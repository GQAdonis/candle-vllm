# Config Generator Agent

## Role

Assemble a complete, valid `models.yaml` configuration file from the outputs of the model-selector and hardware-profiler agents, combined with user preferences.

## Inputs

| Field             | Type     | Required | Description                                      |
|-------------------|----------|----------|--------------------------------------------------|
| model_selection   | object   | yes      | Output from model-selector agent (top recommendation) |
| hardware_profile  | object   | yes      | Output from hardware-profiler agent              |
| user_preferences  | object   | no       | Overrides and optional settings (see below)      |

### User Preferences Schema

```yaml
user_preferences:
  port: 2000                       # server port (default: 2000)
  ui_server: true                  # enable web UI (default: true)
  log_level: "info"                # debug | info | warn | error
  idle_unload_secs: 300            # seconds before unloading idle model
  max_num_seqs: null               # override auto-calculated value
  prefill_chunk_size: 8192         # chunked prefill size (0 to disable)
  enable_turboquant: false         # enable TurboQuant KV compression
  turboquant_bits: 4               # TurboQuant bit width (2, 3, or 4)
  isq: null                        # in-situ quantization level
  block_size: 32                   # paged attention block size
  prompt_cache: false              # enable prompt caching
  parking_lot: null                # custom parking lot config
  extra_models: []                 # additional models beyond primary
  notes: null                      # freeform notes field
```

## Processing Pipeline

### Step 1: Build Model Entry

For each model (primary + any extra_models):

```yaml
- name: "{model_selection.model_name}"
  hf_id: "{model_selection.hf_id}"
  format: "{model_selection.format}"
  gguf_file: "{model_selection.gguf_file}"     # only if format == gguf
  dtype: "{hardware_profile.dtype}"
  device_ids: {hardware_profile.device_ids}
  mem: {hardware_profile.recommended_mem_flag_mb}
  max_num_seqs: {computed_max_num_seqs}
  block_size: {user_preferences.block_size or 32}
  prefill_chunk_size: {user_preferences.prefill_chunk_size or 8192}
```

### Step 2: Apply Quantization

```
if model_selection.recommended_quant:
    model_entry.isq = model_selection.recommended_quant
elif user_preferences.isq:
    model_entry.isq = user_preferences.isq
```

### Step 3: Apply TurboQuant

```
if user_preferences.enable_turboquant:
    model_entry.turboquant:
      enabled: true
      bits: {user_preferences.turboquant_bits or 4}
```

### Step 4: Apply Defaults

Ensure every configuration has these fields set:

| Field              | Default Value              | Notes                            |
|--------------------|----------------------------|----------------------------------|
| idle_unload_secs   | 300                        | Always include                   |
| default_model      | first model in list        | Set to the primary model name    |
| block_size         | 32                         | Must be 16, 32, or 64           |
| prefill_chunk_size | 8192                       | 0 disables chunked prefill      |
| max_num_seqs       | hardware estimate          | From hardware profiler           |
| mem                | kv_cache_budget_mb         | From hardware profiler           |

### Step 5: Validate Combinations

Run these checks before emitting output:

- `device_ids` must be a YAML array of integers.
- If `backend == "metal"`, `device_ids` must be `[0]`.
- If `backend == "cuda"` with multi-GPU, `device_ids` length must be a power of 2.
- `dtype` must be one of: `f32`, `f16`, `bf16`.
- `block_size` must be one of: `16`, `32`, `64`.
- `isq` must be one of: `q4_0`, `q4_1`, `q5_0`, `q5_1`, `q8_0`, `q2k`, `q3k`, `q4k`, `q5k`, `q6k`, or null.
- `turboquant.bits` must be one of: `2`, `3`, `4`.
- `mem` must be > 0.
- `idle_unload_secs` must be >= 0.

### Step 6: Assemble Final YAML

## Output Template

```yaml
# candle-vllm models configuration
# Generated by config wizard
# Hardware: {hardware_profile.backend} / {gpu_type}
# Date: {current_date}

server:
  port: {port}
  ui_server: {ui_server}
  log_level: "{log_level}"

default_model: "{first_model_name}"

idle_unload_secs: {idle_unload_secs}

models:
  - name: "{model_name}"
    hf_id: "{hf_id}"
    # format: {format}
    dtype: "{dtype}"
    device_ids: {device_ids}
    mem: {mem}
    max_num_seqs: {max_num_seqs}
    block_size: {block_size}
    prefill_chunk_size: {prefill_chunk_size}
    # isq: {isq}                    # uncomment to enable in-situ quantization
    # turboquant:                   # uncomment to enable KV-cache compression
    #   enabled: true
    #   bits: 4

# parking_lot:                      # uncomment and customize if needed
#   max_waiting: 100
#   timeout_secs: 60

# notes: "{notes}"
```

When `isq`, `turboquant`, or `parking_lot` are actively configured (not default/null), include them uncommented.

## GGUF-Specific Output

When `format == "gguf"`, the model entry uses `gguf_file` instead of `dtype`/`isq`:

```yaml
  - name: "{model_name}"
    hf_id: "{hf_id}"
    gguf_file: "{gguf_filename}"
    device_ids: {device_ids}
    mem: {mem}
    max_num_seqs: {max_num_seqs}
    block_size: {block_size}
    prefill_chunk_size: {prefill_chunk_size}
```

## Error Conditions

- If validation in Step 5 fails, return the specific validation error(s) instead of a config file.
- If model_selection or hardware_profile is missing required fields, list the missing fields.
- If conflicting settings are detected (e.g., flash-attn requested but cuda_arch < 800), emit a warning and disable the conflicting feature.
